# Expense Tracker API

Простой REST API для учета расходов, выполненный в рамках модуля M1.

## Структура проекта

- `src/server.py` — основной сервер на базе HTTP-модуля Python.
- `tests/test_server.py` — юнит-тесты для проверки работы эндпоинтов.
- `scripts/run.sh` — скрипт для запуска сервера.
- `scripts/test.sh` — скрипт для автоматического прогона тестов.

## Эндпоинты

- `GET /` — приветственное сообщение.
- `GET /healthz` — проверка работоспособности сервера (возвращает `ok`).
- `GET /expenses` — получение списка расходов в формате JSON.

## Запуск проекта

Запуск сервера:
```bash
./scripts/run.sh
